# Lab 1 - Filling Any Polygon

Laboratorio de Gráficas por Computadora desarrollado en **Rust** utilizando **Raylib**.

El programa dibuja y rellena diferentes polígonos a partir de una lista de vértices. También incluye un polígono con un agujero en su interior que no debe ser rellenado.

## Requisitos

* Rust
* Cargo
* Raylib

## Ejecución

Para compilar y ejecutar el proyecto:

```bash
cargo run
```

Al ejecutar el programa se generan los archivos de salida con los polígonos dibujados y rellenados.

## Estructura

El proyecto contiene implementaciones para:

* Manejo de framebuffer.
* Dibujo de líneas.
* Representación de vértices.
* Dibujo y relleno de polígonos.

## Salida

El resultado del laboratorio se encuentra en:

```text
out.png
```

También se genera una versión en formato BMP.
